# ADR-0006:文档体系完整重构契约回归代码与投影

## Context

用户裁定（2026-09-17，D56 连续三令「整个项目没有按 adr 的结构来」「按文档即代码体系完整重构」「老文档都要清退」）。盘点实证：references 层是手维护第二真相（R002 自称命令面唯一权威，66 文件 172 处提及，src 17 文件约 135 行 /// 模板指针）；根目录五件旧四原语簇（INDEX 与 PRD 与 GOAL 与 TODO 与 PLAN）；guide/ 与 guides/ 双目录（2026-09-15 并存裁定）；mistakes/ 与 web/ 不在 doc-gov 地图；R010 仍是 oma 旧口径。dev-evo 舰队收敛口径在册：CLI 检索面 `--llms`、库检索面 aidoc（2026-09-16，hst 为实证样板）。两轮问答裁定：清退形态删除出仓（git 历史即档案，不落 proven 大部）；叙述件（R002、R004 至 R011、G001 至 G005、M 件）全部清退，使用知识靠 `hst --llms`、aidoc、AGENTS 与新写最小 guides 承载。

## Decision

老文档层删除出仓：根目录 INDEX、PRD、GOAL、TODO、PLAN 五件；references 全系（R001 至 R011，含 R002 命令权威与 R011 IO 契约文本）；guide/（G001 至 G005 加模板）；mistakes/（M101 至 M107）；web/；proven/（P 件全文，已由 ADR 与 CHANGELOG 里程碑择要承接）。diary 与 research 是保留核心结构不可裁撤（2026-09-16 用户裁定在册）。公开契约权威五面：clap help（CLI 面）、`hst --llms`（CLI 投影）、模块 `///` 契约注释、tests（行为锁定）、cargo aidoc 投影（库面，`--check --strict` 漂移门禁）。AGENTS 收紧为检索阶梯（投影到 /// 到源码，ADR 按需）；六态标记与禁字规范各一句话进 docs/README（真门禁是工具 mdcharlint 与 rumdl）；环境长事实下沉新篇 guides/环境事实.md。历史件（diary、CHANGELOG、幸存 research）内裸文字提及不改写，活面 md 链接修至零断链。取代 2026-09-15 guide/guides 双目录并存裁定。

## Consequences

- 好：单一真相回归代码与投影；仓库文档面极简（根五件加 docs 六目录）；检索阶梯明确；无手维护参考文档漂移面。
- 坏：R002 累积的行为细则叙事（D/M 历史语境）不再可日常浏览，只在 git 历史可考；六态与禁字规范降为一句话加工具，细则语境靠 research 与工具实现本身；proven 删除后 P 编号仅在 CHANGELOG 与 ADR 指针中存在。
