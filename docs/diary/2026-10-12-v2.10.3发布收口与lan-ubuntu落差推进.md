## 流水

1. **定名批 5ee104e**：Cargo 2.10.2 升 2.10.3，changelog 里程碑（hookstate 插件名前缀双拼修复），aidoc 随版重投影（26 件）；全测 218 加 51 绿，fmt 净，clippy 存量 26 警告零新增，md 四门禁绿。
2. **发布链全绿**：版本闸 tag=2.10.3 加预检（gh 登录、远端 tag 锚 HEAD、无既有 release）加测试闸（cargo 加 md4 加 aidoc strict）加四构建（linux 与 win-gnu 本地，aarch64 与 x86_64 darwin lan-mac 实机）加八资产打包加四端冒烟（linux 加 mac 加 intel-mac 加 win 全 ok hst 2.10.3）加 gh 直发 --latest `[实证: release https://github.com/raystyle/hst_rs/releases/tag/v2.10.3 加链日志全录]`。
3. **三方对齐**：linux 资产 sha256 本地打包 = release 资产边车 = 镜像 stable 段边车 = bdbc6056…；镜像 stable 即到货 `[实证: curl env.ohmygh.com/hst/stable 边车对读]`。三平台边车在册：win zip b8fcedc7…、mac arm64 eea8ba22…、mac x64 399950fe…。
4. **过程坑一笔（当场记）**：发布批首推 main 遇 SSH 瞬断（错误尾行 and the repository exists），而链式命令对 git push 接了 `2>&1 | tail -1` 管道，退出码被 tail 吞、链条继续走完 tag 推送，远端一度 tag 在前而 main 在后；ls-remote 直查发现后重推即齐（双锚 5ee104e 复验）。教训：推送类链式命令禁接输出管道（或先 set -o pipefail），推后必 ls-remote 对锚 `[实证: ls-remote 输出]`。
5. **lan-ubuntu 落差推进**：镜像 stable 到货后探得工位可达（ssh BatchMode），装位 `~/.local/bin/hst` 2.10.2；self update 被管理方布局守卫正确拒守（落痕 `~/.local/bin/ark-managed` 在，提示升级走 ark 滚 catalog pin），非端上自管，落差闭在总台 catalog 锚 `[实证: lan-ubuntu 实弹输出]`。精确落点：ai-ccoe `catalog/tools.toml` 的 `[tools.hst]` 现钉 v2.10.2 与 sha DCD717CA…，bump v2.10.3 需换 sha b8fcedc7…（win zip 边车），滚端归总台 D34 链。
6. **n8 评估结论**：evo-lint hook 的 rustfmt edition 2024 硬编是插件侧（project-evo 仓）缺陷，hst 发布无对应改动面，不入 2.10.3；issue n8 已在统一入口（issues.ohmygh.com）路由，修复归 project-evo 工位派单。
