## 自省

- 昨轮三面统一后本轮仍捞出 13 处残破描述（main 11 加 fmtio 2）：帮助面「看得见的地方」长期带着语病出厂，因为没有任何测试钉描述质量；漂移守卫只锁「在不在册」锁不了「读不读得通」，描述修复靠本轮人工通读。结论：改 CLI 对外面时把全部 `--help` 与 `--llms` 输出通读一遍应是固定动作。同型残破库面还有约百处（codex 评审 G7 实测 105 处，经 aidoc 投影给 agent 读），本轮只清了帮助面可见的，库面债立 REQ-012 排期，不清零不装没看见。
