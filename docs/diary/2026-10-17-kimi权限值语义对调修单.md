# 2026-10-17 kimi 权限值语义对调配平修单 v2.15.1

## 事

总台修单（lan-win w19:p1）：`hst init --yolo` 后 kimi 格仍弹窗、用户报不持久；实锤 = grok 研究单（share/lan-win/c58479c604，yolo-detect-flip.txt）判据表 + 总台实机复现 + 写读同 keys 互证假绿（hst 写 `yolo` 读 `yolo` 判 ok，实机语义高危仍问）。根因：kimi 2.2.0 起值语义与旧 kimi-cli 对调（`yolo` = Ask When Needed、`auto` = Never Ask、`manual` = Always Ask），D33 定分级取值时按旧站口径读，full 落 `yolo` 实为半放行、partial 落 `auto` 反而更放，两档装反。
