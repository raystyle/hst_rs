# REQ-015：hook注册形态迁移评估

## Scenario

issue #31 根因侧：claude 注册面 `~/.claude/settings.json` 是多写方共享文件（Claude Code UI 权限写、herdr 集成安装器、他端会话 stale-snapshot 写），任何非合并写都可能抹掉 hst 注册段。REQ-014 的哨兵自愈是止血；治本在把注册迁到不被外部重写的载体。

## Criteria

- 评估 claude 插件形注册（`~/.claude/plugins/` 带 hooks 面，UI 与外部安装器不重写该目录；md-guard 插件 hook 为在案活例）的可行性、加载时机（会话启动快照）与 D27/D28「零 hst 依赖 shim」哲学的相容性
- codex/grok/kimi 同理盘点各自不可覆盖的注册面
- 裁定输出：迁或不迁（迁则立 ADR 加实施 REQ；不迁则记档理由，REQ-014 哨兵自愈为终态）
