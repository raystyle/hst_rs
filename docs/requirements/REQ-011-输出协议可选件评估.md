# REQ-011：输出协议可选件评估

## Scenario

cli-docs 技能采纳轮（2026-09-18 总台派单）逐件盘点后，输出协议面有三件不进本批：`--schema`（每命令 args、options、output 三面 JSON Schema）、类型化 CTA（信封 meta.cta 建议命令块，人机同源渲染）、细分错误码（stderr 单行形的 code 现为常量 error）。三件都是有真实面价值的协议件，登记在此评估取舍与排期，不静默丢弃。

## Criteria

- [ ] `--schema`：裁定做或不做；做则从 clap 活命令树派生（禁手维护），与 `--llms --json` 机器形同源单一真源
- [ ] 类型化 CTA：裁定做或不做；做则信封 meta.cta 与 kv 面 `Suggested commands:` 块同源渲染，首批落 agents 检测 missing 行（现 hint 字段是同位雏形）
- [ ] 细分错误码：裁定做或不做；做则 error code 按错误类分道（用法、网络、IO、校验），保持 stderr 单行形不变
- [ ] 三件裁定结果回填本 REQ（implemented 或 rejected 加理由），不悬空
