# REQ-002:资产名与关键词取参纯函数重构

## Scenario

host_asset_name 与 host_keywords 用 cfg! 形分支，D47 后 linux CI 连 windows 分支都不编译，gnu 字面量笔误可过 CI（codex D47 评审 F3）。

## Criteria

- [x] 抽 (os, arch) 取参纯函数去 cfg!：`asset_name(os, arch)` 加 `asset_keywords(os)` 加 `asset_arch(arch)` 加 `pick_asset_for(assets, os, arch)` 四个私有纯函数，host 形（`host_asset_name` / `pick_asset`）只转发 `std::env::consts` 常量，`host_keywords` 并入取参形删除 `[实证: 2026-09-16 cargo test --lib update:: 11 绿加全测试 185 加 28 绿]`
- [x] 全平台资产名字面量断言不再跟本机走：六组合（windows 加 macos 加 linux 各乘 x86_64 与 aarch64）表断言加关键词梯子三断言加 host 形零漂移断言，任一 CI 岗全跑；D47 msvc-only 回落判据从 cfg!(windows) 圈内放出，linux/mac 岗同样可断 `[实证: 2026-09-16 linux 本机跑该表即断 windows gnu 字面量，盲区闭合]`
