# REQ-008:三扫描器缺省根统一仓根

## Scenario

mdcharlint 缺省扫描根按 `__file__` 推仓根，md-heading-scan 与 md-ref-scan 按 cwd：非仓根 cwd 下 heading-scan 空扫 exit 0（已复现，codex 评审 O6）、md-ref-scan 直接 FileNotFoundError traceback（默认 allow 路径按 cwd 解析）；同属 M065「门禁脚本对任意入参先自保」一类，09-15 的「退出码 0」观察也因此多一条候选因（非仅 M033 管道吞码）。

## Criteria

- [ ] heading-scan 与 ref-scan 缺省根改 `__file__` 推导仓根（对齐 mdcharlint O7 修法）
- [ ] ref-scan 的 allow 清单路径同基准解析，仓外 cwd 不炸
- [ ] 仓外 cwd 空扫/全扫三器行为一致性实测（裸跑取退出码，不经管道）
