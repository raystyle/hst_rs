# 环境事实

> 平台矩阵、连接姿势与分发体系的长事实（从 AGENTS 环境节下沉，ADR-0006）。只记事实，不记规范。

## 平台矩阵与开发位

- 三平台矩阵：Windows/Linux/macOS；CI 三岗含 windows-gnu 交叉岗。
- 本仓唯一工作根：WSL `~/repos/hst_rs`（VHDX；旧位 `/home/ray/hst_rs` 与 D 盘位已裁撤，2026-09-16 终验在案）。
- WSL 上 Windows 命令用 pwsh 7；md 与 Rust 源 UTF-8；需兼容 PS 5.1 的脚本带 UTF-8 BOM；Windows 侧默认 powershell.exe 5.1 是坑不是选项。

## 5端4机实弹矩阵

- 基建原语 5端4机（2026-09-16 用户定）：wsl 加 lan-win 加 lan-mac 加 lan-ubuntu 加 lan-linux 五端；wsl 与 lan-win 同宿主机共一机。
- `bash .tools/cross-test.sh`：wsl 就地跑、windows-gnu 本地交叉构建、mac 取 dev release 资产、lan 三端 mesh、lan-win 走宿主 127.0.0.1 回环（REQ-007）。
- 连接姿势：WSL 到宿主恒走 127.0.0.1 回环（ssh 加 interop 直调，不走宿主 mesh IP）；lan 三端 mesh 随时随地；口径全文见 dev-evo env-platform 第十节。
- 验收与运维脚本统一载体 pwsh（五端 7.6.6；非登录 shell PATH 兜底 `export PATH="$HOME/.local/bin:$PATH"`）；仓内既有 bash 载体 cross-test.sh 属存量不强制迁移，新增验收运维面一律 pwsh。

## 跨仓与分发

- 跨仓：ark-rs `~/repos/ark_rs`、ohmycloud `~/repos/ohmycloud`、dev-evo 指导仓 `~/repos/project-evo`（WSL VHDX；旧 D 盘位已裁）。
- 分发体系：omc 管分发运维、ark 管落地执行验收；本仓自升级三通道在册（GitHub 直连、镜像腿带缺省回退（env.ohmygh.com）、`--git` 源码）。
- 镜像段：`https://env.ohmygh.com/hst/<seg>/`（seg 随通道，stable 段随 tag 滚动）。
- 版本载体唯一权威 Cargo.toml（semver：修复与文档批 patch、能力与行为变化 minor、契约破裂 major；载体外版本号即第二真相）。
